# Full-Stack Fruits JWT Authentication App

Full-stack TypeScript & Express REST API with stateless JWT authentication, bcrypt & SQLite.

## Architecture
- **Backend**: Express.js, TypeScript, SQLite (`better-sqlite3`), JWT (`jsonwebtoken`), and bcrypt password hashing.
- **Frontend**: Vanilla TypeScript, HTML5 & modern CSS with responsive reactive state store.
- **Security**: Bearer token authentication middleware, password salting/hashing, protected REST routes.
